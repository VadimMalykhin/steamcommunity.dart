# SteamCommunity.dart

A Dart package providing access to the Steam Community.

## Installation

Add this to your `pubspec.yaml`:

```yaml
dependencies:
  steamcommunity:
    git:
      url: https://github.com/VadimMalykhin/steamcommunity.dart.git
      ref: main
```

Or run this command in your terminal:

```
dart pub add steamcommunity --git-url=https://github.com/VadimMalykhin/steamcommunity.dart.git --git-ref=main
```
